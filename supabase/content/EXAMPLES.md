# Reference examples — collection sheet

Goal: ~5 authentic example questions **per subject** so Claude can calibrate the
style, phrasing, and difficulty, then write **original** questions in the same mold.

**These samples are reference only.** They will NOT be shipped verbatim — they exist
so generated originals feel like the real exam. Paste them in plain text below each
subject; don't worry about JSON or formatting. A photo you've typed out is fine.

For each example, the more of this you include, the better:

```
Difficulty: easy | medium | hard
Question: <the question text>
Options:
  1) ...
  2) ...   ✓ correct
  3) ...
  4) ...
Why: <one line on why the correct answer is correct>
```
